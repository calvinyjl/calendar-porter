# calendar-porter

This is a WIP web app that ports your QMUL calendar over to a .ics file, compatible with Google Calendar, iCalendar etc.

How to use:
1. Setup a virtual environment
2. Install the requirements from `requirements.txt` 
3. Run the command `npm install` to install node modules
4. Double check the `index.js` file, and make sure the `START_DATE` and `REFERENCE_WEEK` are correct
5. Run the command `npm start`
6. Head to localhost:5000 and type in your student ID
